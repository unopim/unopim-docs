# Manually Install UnoPim

This section describes the **manual installation process** for **UnoPim**.

Manual installation requires preparing the server environment first,
followed by installing UnoPim using one of the supported manual methods.

## Installation flow

The manual installation process consists of the following steps, which
must be completed in order:

1. **System Requirements**
   Ensure the server meets all hardware, OS, PHP, and extension requirements.

2. **System Installation**
   Configure the operating system, web server, database server, and PHP runtime.

3. **Install UnoPim**
   Install UnoPim using **Composer** or the **GUI Installer**.

## Manual installation methods

After completing the system preparation steps, choose **one** of the
following methods to install UnoPim.

### Install via Composer

Use this method if you want full control over the codebase and configuration.
This approach is suitable for local servers and custom deployments.

➡️ Continue with:
[**Install UnoPim via Composer**](./composer)

### Install via GUI Installer

Use this method if you prefer a browser-based installation flow after the
system environment is ready.

➡️ Continue with:
[**Install UnoPim via GUI Installer**](./gui-installer)

## Notes

* System requirements and system installation must be completed first
* Follow only one manual installation method per setup
